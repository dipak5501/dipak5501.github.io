What Dipak Yadav built

This thesis by Dipak Yadav asks whether automated checks can reject UML diagrams that look finished but are wrong. The running application turns natural-language requirements or source code (Java, Python, C) into design-phase UML (class, object, component, package), renders black-and-white PlantUML images, and scores them with a multimodal VLM ensemble.

Pipeline: three-stage tech spec → PlantUML → render + VLM scoring · composite score S and majority-vote gate A · FastAPI + Streamlit app with analytics and export · fine-tuned PlantUML LoRA on Apple Silicon for code → UML stages.

The live demo URL can change when the public tunnel restarts. Prefer this thesis page for a stable link; use Open live thesis app for the current running demo.
