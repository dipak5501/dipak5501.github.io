What Dipak Yadav built

This thesis asks whether automated checks can reject UML diagrams that look finished but are wrong. The application turns natural-language requirements or source code (Java, Python, C) into design-phase UML, renders PlantUML images, and scores them with a multimodal VLM ensemble.

Three-stage pipeline: tech spec → PlantUML → render + VLM scoring · composite score S and majority-vote gate A · FastAPI + Streamlit · fine-tuned PlantUML LoRA on Apple Silicon.
