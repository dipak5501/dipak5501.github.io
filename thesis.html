What Dipak Yadav built

This thesis by Dipak Yadav asks whether automated checks can reject UML diagrams that look finished but are wrong. The running application turns natural-language requirements or source code (Java, Python, C) into design-phase UML (class, object, component, package), renders black-and-white PlantUML images, and scores them with a multimodal VLM ensemble.

  • Three-stage pipeline: tech spec → PlantUML → render + VLM scoring
  • Composite score S and majority-vote gate A
  • FastAPI + Streamlit thesis application with analytics and export
  • Fine-tuned PlantUML LoRA on Apple Silicon for code → UML stages
